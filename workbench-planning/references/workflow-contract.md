# 流程状态与操作契约

用于衔接工作台各模块、判断下一步和解释结果。当前是本机工作台流程，不是自动运行的外部 Agent OS。

## 判断入口

| 用户意图 | 合适入口与结果 | 不要替换成 |
| --- | --- | --- |
| 只问规则、日期、进度 | 查当前项目资料并引用依据 | 自动生成任务或修改日程。 |
| 新目标，需要规划如何完成 | 规则／目标→差距与能力→补齐选择→任务草稿 | 从课表起步，或把所有建议强塞进去。 |
| 通知里已经明确列了事项 | 资料转待办，核对日期和来源后确认 | 重新设计一整套目标。 |
| 调整已有计划 | 基于最新草稿或正式待办生成修改预览 | 没查现状就重建全部任务。 |
| 安排一天具体钟点 | 读取占用、正式待排和池候选，给日程建议 | 默认把池里的所有事项今天做完。 |
| 查看或清理课表 | AI 助理读取共享固定时段；清理时按日期／课程筛选、勾选，再确认 | 以没有项目目标／草稿为由拒绝读取，或把清理描述成已执行。 |
| 已经做完，需要记账 | 指明任务和归属日，记录实耗、产出或完成状态 | 把计划分钟当成实际分钟。 |
| 整理经验 | 指定日期／项目，生成五问复盘，核对后归档 | 凭空生成不存在的完成记录。 |

## 最少上下文

需要动任务或日期时，核对项目、用户目标、已确认规则、硬截止、固定占用、已有任务状态，以及该动作需要的预算或能力回答。资料中未知字段保持未知，预估明确标注。对不影响本次动作的缺项，不反复追问。

有工具时优先使用已有项目记录；没有工具时让用户提供相关片段，或产出待确认稿。不能猜测自己具有某个 MCP、文件写入或外部账户权限。

## 结果状态

| 状态 | 可以说什么 | 下一步 |
| --- | --- | --- |
| 分析／建议 | 已根据这些资料给出建议，指出依据和缺项 | 用户核对，不宣称已写入。 |
| 已生成预览 | 已有待核对的任务、日期或时段 | 可修改、移除、放弃，处理冲突。 |
| 已保存草稿 | 草稿内容和版本已保存 | 在项目排期确认应用；不要说正式日程已更新。 |
| 待确认 | 标明实际新增／修改、项目、日期与来源 | 使用对应确认入口，不要求已经确认的同一内容重复确认。 |
| 已写入 | 操作成功且回读目标位置一致 | 提供结果位置、条目数和剩余未安排事项。 |
| 失败／未验证 | 哪一步失败、未执行什么、保留了哪些结果 | 给补资料、改时段或重新生成等具体恢复路径，不虚报完成。 |

不要求所有类型都走草稿：资料归档、课表、单次固定时段、资料转待办和每日建议有自己的确认流程。已有明确授权可继续准备工作，但当前产品规定的正式应用确认点仍保留。

课表清理只移除预览中经勾选的共享固定时段，不删除任务、普通日程或课表原图。默认查询今天起的时段；历史日期须显式调整筛选。新版图片导入记录标记为导入，手工固定块标记为手动；旧版记录来源未知，默认不选，不能按项目名称猜测归属。需要批量处理旧版时先筛选核对，再使用“选中当前列表全部（含手动及旧版时段）”。清理不可直接撤销，可重新导入。预览 30 分钟有效，一次使用；条目已变化时整体拒绝，重新读取后核对。明确的“查看现有课表”“帮我清空课表设置，我要重新导入课表”可直接路由，无须模型调用；复杂自然语言筛选仍依赖已配置模型。

## 数据去向与回读

| 产出 | 保存位置／回读位置 |
| --- | --- |
| 规则、目标、差距及能力对应依据 | 当前项目知识库；能力答案和补齐选择还进入能力档案。 |
| 任务树与建议日期 | 项目草稿；正式应用后到月总览／项目排期。 |
| 有执行日但无时段的事项 | 该日待安排区。 |
| 无日期事项 | 对应项目待分配池；每日建议确认后才定日并移出。 |
| 具体钟点 | 对应日时间表，检查固定占用和实际写入条目。 |
| 实耗与执行变化 | 时间日志、执行记录；按任务和归属日期核对。 |
| 确认后的复盘 | 项目知识库，可另存 Markdown。 |

模型答复、对话记录、操作确认记录、正式任务不是同一种数据。查询结果要指出依据来自哪里；不能仅凭对话里一句“已完成”就当作数据库已更新。

## 冲突和恢复

- 期限冲突：区分报名、作品提交、执行日及原文版本，列出出处再核对。
- 草稿变化：以最新版本重新生成修改建议，不把旧预览覆盖到新草稿。
- 日程冲突：固定课程优先保护。含待分配候选的批次会在失效、占用或预算不足时回滚；只含正式任务的应用可能跳过不可用项，必须回看实际结果。
- 能力依据缺失：保留初步差距、明确缺少证据。重新生成对应表，不伪造能力验证。
- 删除或跨状态：区分取消当天时段、重新打开任务、普通不可恢复删除及缓冲舍弃。先按页面说明核对影响。
- 文件操作：受支持内容可读取和另存新稿；不能推断能编辑任意文件格式或写入任意本机目录。

## 演示与说明

以同一项目、同一组任务展示输入→理解→预览→确认→目标页面回读→执行→复盘。标注示例数据、模拟模型和未验证步骤；没有录制视频就不能说已完成录屏。

说明采用用户能操作的入口、确认按钮与结果位置，不堆内部实现名词。未完成的归档重命名、重复目标规则、后台定时和外部接入明确列为待办，不自动启动开发。
