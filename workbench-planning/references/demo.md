# 课程资料到日程演示

这是一条可选演示路径，不表示产品只面向课程。其他四类可用以下虚构目标，仍按已确认资料、差距、任务、排期和复盘核对：

| 类别 | 示例目标 | 核对重点 |
| --- | --- | --- |
| 竞赛 | 完成可演示原型、说明和提交材料 | 提交截止与报名截止分开；必要的后端、测试和演示不漏项。 |
| 考研 | 本周完成指定题组并复盘错题 | 固定学习占用、每日预算、实耗，不能声称已有完整复习节律模型。 |
| 副业 | 完成一份自己确定的成果 | 核心范围、审核节点、实际产出；不自动对外发送。 |
| 学校作业 | 根据作业要求完成报告与附件 | 适用对象、提交格式、证据和截止，不编造完成记录。 |

以下演示只核对输出。需要实际写入时，在已连接的工作台确认，并到月／日视图回读；没有连接时不宣称已经创建。

以下是虚构示例。可以把整段输入发给已加载 Skill 的 Agent，无需启动工作台。

## 输入

> 以 2026-11-17 为基准，时区 Asia/Shanghai。继续安排「AI 产品经理课程」。已确认目标是按时交课程案例作业。课程公告写明：报名确认截止 11 月 18 日 12:00，案例作业提交截止 11 月 20 日 18:00。讲义要求交一页问题定义和三条访谈摘要。访谈已经做完，实际用了 45 分钟。11 月 17 日晚上我只有 19:00–21:30 有空，但 19:30–20:30 有固定课程。还想在当天 20:00–20:30 做作业，请先给安排预览，暂不写入。

## 预期结果

| 核对项 | 正确表现 |
| --- | --- |
| 证据 | 分开列报名确认和作业提交两个期限，说明来自课程公告，列出讲义要求 |
| 任务续接 | 保留访谈已完成及 45 分钟记录，安排整理摘要和撰写问题定义 |
| 冲突 | 指出请求的 20:00–20:30 与固定课程重叠，给出 19:00–19:30 或 20:30 后的可选时段 |
| 审核 | 明确结果当前为预览，待用户确认后才写入 |
| 复盘 | 报告已有实际工时，无原始估算时说明无法比较 |

第二轮可改用「竞赛通知 + 截止日 + 作品提交任务」，沿用同一流程。再用十项当天待办测试超量提醒，检查固定安排和硬截止是否保留。记录实际运行所用AI 工具、输入、结果和修正。只有已验证的功能才写入使用说明。
